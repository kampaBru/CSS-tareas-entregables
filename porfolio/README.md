# 💼 Portfolio - Adam Keyes (Frontend Mentor Challenge)

Proyecto basado en el reto de Frontend Mentor para construir un portfolio responsive con HTML, TailwindCSS y Vite.

---

## 🚀 Tecnologías

* HTML5
* TailwindCSS
* Vite
* Responsive Design (Mobile First)

---

## 🎯 Objetivo

Reproducir un diseño profesional adaptado a múltiples resoluciones:

* Mobile
* Tablet
* Desktop (hasta 1280px)

---

## ⚙️ Características

* Layout responsive limpio
* Uso de `container-global` para consistencia
* Imágenes decorativas posicionadas correctamente
* Hero con overlay y composición avanzada
* Hover effects en proyectos

---

## 🧠 Aprendizajes clave

* Gestión real de breakpoints (sin abusar de 2xl/3xl)
* Posicionamiento absoluto correctamente anclado (`relative`)
* Separación entre layout y decoración
* Control de spacing (margin vs padding)
